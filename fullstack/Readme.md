## Capstone project categories

### Full frontend app
*frontend capstone · build it in your stack's framework*
- **Interactive SPA** — Build a stateful single-page app (dashboard, tracker) with React or Angular, proper state management, and responsive CSS.
- **API-driven UI** — Build a UI that consumes a real API, handles loading/error states, and manages server state cleanly.
- **Component library** — Build a small reusable component set with consistent theming.

### REST API + database
*backend capstone*
- **Secure CRUD API** — Build an Express API with a designed schema, full CRUD, and JWT auth.
- **Role-based backend** — Add authorization and roles to a real API with proper access control.
- **Validated API** — Build an API with rigorous input validation and error handling to spec.

### Full-stack app
*flagship capstone · one build per stack*
- **MERN build** — MongoDB + Express + React + Node, with auth, deployed. The document-database mental model end to end.
- **MEAN build** — MongoDB + Express + Angular + Node — same backend, a DI-and-RxJS frontend.
- **PERN build** — Postgres + Express + React + Node — same shape as MERN, but a designed relational schema underneath.
- **End-to-end product** — Build a full-stack app (Next.js or Angular SSR + API + database) with auth and deploy it.
- **Real feature clone** — Clone one core feature of a real product end-to-end (e.g. a commenting system).

### Production deployment
- **Ship with a pipeline** — Containerize an app, set up CI/CD, deploy it, and add error + uptime monitoring.
- **Performance pass** — Take a deployed app and measurably improve its Core Web Vitals.
- **Incident-ready app** — Instrument an app so a production error surfaces to you within minutes.

### AI-powered web app
- **LLM feature** — Build a web app feature powered by an LLM API with streaming UI.
- **RAG assistant** — Build a retrieval-augmented chat over your own documents, end-to-end.
- **Rate-limited AI service** — Wire an AI feature with proper cost and rate-limit handling for production.
