# Development Roadmaps

A collection of structured, project-based learning roadmaps covering different areas of software development.

Each domain contains learning nodes, practical projects, and objectives to help learners move from fundamentals to advanced concepts through hands-on implementation.

## Learning Domains

| Domain | Focus |
|---|---|
| Full-Stack Development | MERN, MEAN, PERN |
| Frontend Development | Modern frontend development |
| Python | Python programming and development |
| PHP | PHP development |
| Java | Java programming and development |
| .NET | Microsoft .NET ecosystem |

## How It Works

Each roadmap is organized into:

- **Learning Nodes** — Topics arranged in a progressive learning path.
- **Projects** — Practical projects associated with each learning node.
- **Objectives** — Clear outcomes to achieve through each project.
- **Project Levels** — Accessible, Core, and Stretch.
- **Capstone Projects** — Larger projects that combine multiple concepts.

## Learning Approach

1. Follow the learning nodes in order.
2. Understand the concepts before starting projects.
3. Complete the Accessible project to unlock the next node.
4. Work on Core and Stretch projects to strengthen your skills and earn XP.
5. Apply what you've learned through capstone projects.

## Goal

Learn by building real projects, develop practical engineering skills, and create a portfolio that demonstrates your abilities.
